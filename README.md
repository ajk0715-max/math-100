# 학교 가는 100일

7세 아이의 초등학교 입학 준비를 돕는 100일 학습 웹앱(PWA)입니다. 하루 15분, 수학·시계·달력·생활을 게임처럼 익히고, 부모는 PIN 뒤의 화면에서 진도와 시간을 관리합니다.

- 기획서: Claude 문서 「100일 초등 입학 준비 학습 앱 기획서」
- 학습 기록은 아이 기기 안(IndexedDB)에만 저장됩니다. 서버로 보내지 않습니다.

## 개발

- `npm run dev` 개발 서버, `npm run build` 운영 빌드, `npm test` 테스트, `npm run typecheck` 타입 검사.
- 정답 검증: `tests/semantics*.test.ts`는 문제를 만든 코드와 따로, 화면에 보이는 글·그림·보기만으로 정답을 다시 계산합니다. 새 문제 모양을 추가하면 검사기도 함께 늘려야 테스트가 통과합니다(알아보지 못한 모양은 실패로 처리).
- 점검 화면: `NEXT_PUBLIC_LAB=1`로 빌드하면 `/lab`에서 스킬·단계·시드를 골라 문제를 띄워 볼 수 있습니다. 운영 빌드에서는 열리지 않습니다(404).
